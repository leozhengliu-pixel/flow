# Inter

`InterVariable.woff2` is the unmodified `web/InterVariable.woff2` from the
[official Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1).
Its embedded version is `Version 4.001;git-9221beed3`. The release tag and
embedded font version use different numbering.

SHA-256: `693b77d4f32ee9b8bfc995589b5fad5e99adf2832738661f5402f9978429a8e3`.

`InterVariable-Italic.woff2` is the unmodified `web/InterVariable-Italic.woff2` from the same release (italic text uses the
real italic face instead of a slanted upright one).

SHA-256: `e564f652916db6c139570fefb9524a77c4d48f30c92928de9db19b6b5c7a262a`.
