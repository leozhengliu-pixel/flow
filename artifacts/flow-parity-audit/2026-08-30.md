# Flow Full-Product Parity Audit

Date: 2026-08-30

## Method

- Walk every reachable workspace route and its create, edit, empty, filtered, archived, selected, disabled, hover, focus, open, and mobile states.
- Measure rendered DOM geometry and computed typography, color, border, radius, shadow, layout, and animation values.
- Exercise nested menus with pointer and keyboard input instead of inferring behavior from screenshots.
- Inspect the loaded client asset graph, compiled stylesheet, fonts, inline SVG sprite, editor, date parser, filter, state-store, routing, collaboration, and draft modules.
- Verify every visible command reaches a real data mutation, navigation, or explicitly supported disabled state.

Flow route inventory covered 54 application route kinds and 27 settings pages.

The machine-readable static inventory and architecture comparison are in `static-resource-summary.json` beside this report.

## Architecture Comparison

| Area | Reference implementation | Flow implementation | Action |
| --- | --- | --- | --- |
| State graph | Observable normalized entity store | Typed React state over REST bootstrap data | Retained: Flow API is authoritative and realtime reconciliation is already centralized |
| Transport | GraphQL operations plus realtime subscriptions | REST mutations plus SSE/realtime presence | Retained: behavior is covered without adding a parallel transport stack |
| Draft persistence | Indexed client storage with nested draft metadata | Local draft plus server Draft entities | Retained and audited; server drafts provide cross-device durability |
| Collaborative editor | Yjs and ProseMirror | Yjs through Tiptap/ProseMirror | Matched |
| Fuzzy dates | Lazy natural-language date parser with period precision | ISO/period parser plus lazy `chrono-node` natural-language parsing | Fixed |
| Styling | StyleX tokenized atomic output | Tokenized domain CSS and CSS modules | Shared measured foundations and regression checks added |
| Icon delivery | Hidden page-local symbol sprite plus inline state SVGs | Core/property/milestone sprites are injected into the HTML; the extended icon catalog remains lazy | Critical states/actions use measured inline paths without common first-frame sprite requests |
| Bundling | Fine-grained route/vendor chunks | Vite route chunks | Vendor code-splitting groups added |

The 52 exact duplicate root selectors between the legacy Initiatives sheet and the measured parity sheet were mechanically merged without changing the cascade. The remaining legacy rules belong to detail, roadmap, media-query, or non-overlapping states.

## Shared Measured Foundations

- Inter Variable, normal weight `450`, medium `500`, semibold `600`.
- Quick transition `100ms`, regular transition `250ms`, fade-out `150ms`.
- Rounded command surfaces use `9999px`; menus use `12px`.
- Menu shadow: `0 3px 8px`, `0 2px 5px`, `0 1px 1px` at 12.5% black in dark mode.
- Dark elevated surface `lch(12.72% .85 272)` and border `lch(25.68% 1.93 272)`.
- Light elevated surfaces use `lch(100% 0 282)` and soft three-layer shadows.

The `check:ui-foundations` lint gate now protects the font hash and measured tokens. `check:functional-controls` rejects explicit no-op click/select/change/submit handlers.

## Product-Domain Results

### Issues

- Rebuilt parent/sub-issue breadcrumb semantics and removed the duplicate parent property.
- Replaced Backlog, Todo, In Progress, and In Review states with measured inline SVG paths.
- Rebuilt sub-issue display controls as Portal-backed pickers and added SLA, milestone, customer, and revenue properties.
- Reused the full property context menu on board cards and preserved checkbox geometry when status is hidden.
- Added document/link resources, Cycle actions, and Copy URL/ID/title actions.
- Removed stale Yjs awareness when a collaborator disconnects.
- Completed real pull-request associations by reusing `CodeReview.issueIds`: manual link/unlink, identifier inference from webhook title/body/branch, issue activity, detail display, external navigation, and unlink actions are all persisted.

### Projects, Initiatives, and Views

- Restored the measured two-row Views header and removed a non-reference tab.
- Rebuilt Projects list/group/row geometry, dynamic status color/progress SVGs, group actions, manual ordering, and API-backed positions.
- Added cross-group Board drag/drop, keyboard movement, and data-driven Timeline ranges.
- Added Initiative Roadmap pointer/keyboard date movement and shared date/status helpers.
- Preserved reference entity routes, owner/move/subscription menus, and API-backed display defaults.

### Workspace, Navigation, and Settings

- Added persisted sidebar visibility/order and count/dot badges, plus real default-home routing.
- Rebuilt Reviews structure, empty SVG animation, disclosure groups, and comment shortcuts.
- Rebuilt Agent geometry, examples, and responsive states.
- Completed Members, Teams, Asks, Preferences, Security/MCP/application approvals, Team settings, and Audit menus.
- Removed unsupported empty account and workspace-document commands rather than leaving inert UI.
- Completed authentication, password recovery, email verification, OAuth error, onboarding, account, region, command, and help states.
- Connected workspace creation, switching, and rename flows to the configured default home instead of a hard-coded workspace route.
- Rebuilt Loops, Workspace Search, Team Documents, and document presence handling; all visible commands now mutate state, navigate, retry, or render as an explicitly disabled capability.
- Replaced every production `window.prompt` and `window.confirm` with one Portal-backed Action Dialog supporting confirmation, text input, destructive emphasis, keyboard control, both themes, mobile width constraints, and a stable `z-index: 1501`.

### Releases, Cycles, and Customers

- Verified release pipeline directory, release detail/editor, notes, resources, status SVGs, and issue list behavior.
- Added the measured 288px current-cycle summary/trend expansion, mobile layout, real document routes, and the link shortcut.
- Corrected Customer dark-theme fallbacks and added copy URL, size, revenue, real request counts, keyboard refresh, sortable headers, and measured column order.

### Backend and Transport

- Isolated notification mutations by recipient and rejected ambiguous empty-ID batch operations.
- Added atomic claims for email and integration deliveries to prevent concurrent duplicate sends and preserve terminal state after disconnects.
- Collapsed overflowing SSE queues to one resync signal; reconnecting clients bootstrap again and short-window multi-issue events no longer overwrite each other.
- Added draft size/type/resource validation, upload `nosniff` and sandbox CSP headers, forced download for active content, import aggregate limits and cleanup, and administrator-only private exports.
- Tightened OAuth request size, grant, response type, and metadata URL validation.
- Validated email intake size, sender, attachment URLs, current team authorization, and message idempotency inside the transaction.
- Added a continuously running SMTP/integration delivery scheduler with `NextAttemptAt`, exponential backoff, an eight-attempt ceiling, atomic claims, graceful shutdown, and Redis leader election. Without Redis it runs as a safe single-instance scheduler.
