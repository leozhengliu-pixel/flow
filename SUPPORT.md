# Support

Flow is a community-maintained open source project. There is currently no
guaranteed response time or commercial support agreement.

## Usage Questions

Before requesting help:

1. Read the setup and configuration sections in [README.md](README.md).
2. Search the [documentation](docs/) and existing [issues](https://github.com/leozhengliu-pixel/flow/issues).
3. Verify the issue against the latest `main` branch.
4. Run the frontend and backend quality checks documented in the README.

If the problem remains, open a
[bug report](https://github.com/leozhengliu-pixel/flow/issues/new?template=bug_report.yml)
with reproduction steps, environment details, relevant logs, and the smallest
example that demonstrates the behavior.

## Feature Requests

Use the
[feature request form](https://github.com/leozhengliu-pixel/flow/issues/new?template=feature_request.yml).
Describe the user problem, not only the proposed control or implementation.

## Security and Conduct

- Report security vulnerabilities privately according to [SECURITY.md](SECURITY.md).
- Report Code of Conduct incidents through the private process in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Public issues containing credentials, private data, or exploit details may be
edited or removed to protect users.
