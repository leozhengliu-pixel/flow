# Backlog

The backlog holds issues and ideas that are not ready for active work.

Open a team's Issues page and select Backlog to review them. Create new issue
starts an issue in that team's backlog.

When an issue is ready, change its status to Todo or In Progress. You can also
assign an owner, set its priority, and add it to a cycle from its properties.
Adding a cycle does not automatically change the issue's status.
