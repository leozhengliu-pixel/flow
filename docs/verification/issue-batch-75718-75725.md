## Behavioral Details

The selection toolbar's downloaded reference bundle uses `placement: top`, an
offset of 6px and viewport overflow padding of 12px. Its apparent left alignment
in a single screenshot results from collision handling, not a fixed -58px
translation. Flow now uses the same positioning rule. The toolbar measured 36px
high with fourteen controls and 16px primary glyphs in the local browser.

Comments created from selected text store the quote and original positions in
the existing structured comment data. Editing a comment preserves the anchor.
Clicking the quote selects the original range when still valid, with text lookup
as a fallback when earlier edits have moved it. This is not a new independent
thread-resolution or document-permission system.

Compact issue-detail bootstrap retains metadata required for navigation and
pickers, but excludes project descriptions/history, document bodies, comments
and update bodies. The response is marked as incomplete so navigating to a
project/document waits for the full response instead of mounting an editable
empty body. The underlying stored data is not modified by projection.

## Test Evidence and Limits

- The final targeted frontend run passed 115 tests across 22 files. A previous
  broader concurrent run hit a 5-second timeout in an existing project filter
  test; its isolated rerun and the final run with two workers passed.
- Server/store package tests passed without race instrumentation. Store-wide
  race tests passed. The full server race run exhausted the default 10-minute
  package timeout, without a reported data race; all change-specific server
  race tests passed in a separate run.
- A deliberately repetitive 13.6MB synthetic JSON response compressed to 98KB
  using gzip best-speed. This proves transport compression, not the compression
  ratio or load time of the production workspace.
- Browser verification used an isolated local database and account. The reported
  production 5.3-second cold session delay was not reproduced or attributed to
  a specific gateway/database cause. Server-Timing now separates application
  time from download/transport time for deployment verification.
- Existing production-sized metadata, real gateway compression behavior and
  cold-login latency still require post-deployment measurement. No production
  rollout or claim that all visual states are pixel-identical is included.
